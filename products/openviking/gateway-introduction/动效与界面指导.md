## 0. 先说清楚：PPT 感从哪来，这次怎么避开

对照 codex V3 试片（26 秒处）和团队版参考片（70 秒处）的单帧：

| PPT 感的来源 | V3 的表现 | 这次的规则 |
|---|---|---|
| 以“页”为单位组织 | 左上角章节号 + 大标题 + 两张卡 + 底部说明，每段重排一次 | **整片是一个世界，镜头在里面移动。** 不存在“下一页”，只有镜头去下一个地方 |
| 标题在讲解 | “需要留存文件，模型选择工具。”这种句子当屏幕主标题 | **屏幕上的字就是界面里的内容。** 全片只有 6 处大字（见脚本总表），其余文字都属于某个窗口、卡片或日志 |
| 免责声明印在画面上 | “文件导入有独立工具路径，不由 Session commit 自动抓取。” | **画面不印说明句。** 边界靠选材守住；最多一个角标（`原理示意` / `开源版界面示意`） |
| 物件没有内部状态 | “请求”矩形穿过“Gateway”矩形，只换标签 | **物件带真实内容并且会变。** 消息胶囊上能读到原句，记忆卡有路径和摘要，贴上去后胶囊会变长 |
| 没有景深 | 所有元素同样清晰，平铺在同一平面 | **只有焦点清晰。** 非焦点层模糊加降低透明度，就像团队版里退到背景的聊天窗口 |
| 没有声音 | V3 无配音无音效 | **无音乐，但旁白 + 音效从样片阶段就要有**，否则无法判断节奏 |

## 1. 视觉基调

- **底色**：纸白 `#F2F4F6` 到 `#F7F9FA` 的极浅渐变，局部有大面积、低饱和的青色光晕（直径约 1200px，`#4FD6F0` 透明度 6–10%），光晕跟着焦点缓慢漂移。
- **品牌色**（来自《OpenViking 标志规范》v1.0）：墨黑 `#07090D` 用于正文和模型节点；信号青 `#4FD6F0` 只用于发光和描边；深海青 `#0A7C93` 用于浅底上的青色文字和小字链接。
- **职责色**（只表示功能，不做装饰）：
  - 青色 = 记忆 / 召回 / 存回（OpenViking 的东西）
  - 紫色 `#7C6CF0`（降饱和后约 `#8B80D9`）= 模型发起的工具调用
  - 墨黑 = 模型
  - 中性灰 = 客户端界面、网关控制台
- **字体**：中文 Noto Sans SC；英文、品牌字标 Geist SemiBold；代码、URI、地址用 JetBrains Mono。
- **字号**（1080p 下）：大字 96–120px，字重 700，字距 -2%；窗口内正文 26–30px；辅助信息不小于 22px，**只在静止时出现**。
- **容器**：白底，1px `rgba(7,9,13,0.06)` 描边，圆角 14–18px。阴影用两层柔光：`0 1px 2px rgba(7,9,13,.04), 0 18px 48px rgba(7,9,13,.08)`。**禁止硬阴影和厚边框。**
- **Logo**：OpenViking 标志按规范使用，可以整体移动或淡入，不拆、不变形、不当隧道。第三方 Logo 只用官网 Integrations 页已有的原始素材。

## 3. 相机系统

- **实现**：一个 `#world`（5760×3240）放在 `#camera` 里，相机只改 `#world` 的 `translate` 和 `scale`。封装一个 `cam(x, y, scale, dur, ease)`，所有镜头只调用它。**不允许各段各自摆位置。**
- **运镜曲线**：长距离移动用 `power3.inOut`，1.4–2.2 秒；跟随物件时用 `power2.inOut`，相机比物件晚 0.12–0.2 秒启动（物件先动，镜头跟上，避免“镜头拽着东西走”）。
- **停稳**：每次运镜结束后至少停 1.2 秒，这段时间里内部状态继续变化（打字、扫描、流式输出），这是“停留时依然有进展”。
- **景深**：每个对象属于一层：`focus`（0px 模糊，透明度 1）、`near`（4px，0.75）、`far`（10px，0.45）。焦点切换时用 0.5 秒补间改层级。全片任何时刻只有一个 focus 区域。
- **视差**：背景光晕层按相机位移的 0.3 倍移动，前景浮尘（极少，可选）按 1.15 倍，中景按 1 倍。
- **透视**：只有 ④ 记忆库是带透视的地面（`rotateX(55deg)`，透视距离 2400px）。窗口和卡片始终正对镜头，保证文字可读。卡片从地面升起时，从 55° 补间到 0°。
- **不做**：不旋转相机，不做手持晃动，不做 3D 穿越隧道，不做全屏闪白转场。

## 4. 物件手册：每个物件都有身份和状态

同一个物件在全片保持形状、颜色和文字，只在状态间变化。**禁止换场时重新画一个“看起来差不多”的物件。**

### 4.1 消息胶囊（主角）

| 状态 | 外观 | 进入方式 |
|---|---|---|
| 输入中 | 输入框里的文字 + 光标 | 打字，每字 40ms，标点后停 120ms |
| 气泡 | 聊天气泡，右对齐，浅灰底 | 回车后从输入框升起，0.35s |
| 胶囊 | 收窄成药丸形（高 56px），保留首行文字，左侧一个小用户头像点 | Flip 变形，0.55s，`power2.inOut` |
| 胶囊 + 记忆 | 胶囊末尾接出一截青色描边段，写着记忆摘要 | 记忆卡飞来贴合，0.3s，到位后 2px 回弹 |
| 胶囊 + 工具结果 | 再接一截紫色段 `read → 原因：支付回归测试未完成` | 同上 |
| 回复 | 模型节点吐出回复流，沿原路回客户端，展开成回复气泡 | 逐词流式，每块 60–90ms |

### 4.2 记忆卡

- 结构：上方一行 URI（JetBrains Mono，22px，深海青），例如 `viking://user/linxia/memories/events/release-plan.md`；下方一行摘要（Noto Sans SC，26px）；右上角类型标签 `事件` / `偏好`。
- 状态：休眠（在记忆库地面里，灰度，far 层）→ 命中（青色描边从左到右扫过 0.5s，摘要文字变清晰）→ 升起（从地面透视回正，0.6s）→ 飞行（MotionPath 弧线，0.9–1.2s）→ 贴附（成为胶囊的一段）。
- 新记忆诞生（06g、07）：几行对话文字向中心收拢（0.5s），压缩成一张新卡（0.3s），落进地面对应目录（0.6s）。**这是全片唯一的“生成”类动画，留给存回这件事。**

### 4.3 网关

- 不是方框。是一块竖立的磨砂玻璃闸门（宽 360px、高 900px，白色 70% 透明加背景模糊），中间一道细光缝，消息穿过时光缝亮起。
- 闸门上有三个端口，文字直接取自官网：`召回`（朝下）、`存回`（朝下）、`工具`（朝右）。端口只在被用到时点亮。
- 闸门顶部小字 `api.vikingdb.cn-beijing.volces.com`（地址的域名部分，完整地址放不下），与 03 镜改进去的地址对应。这是“你改的那行地址”和“这个东西”之间的视觉连接。

### 4.4 模型节点

- 墨黑圆角方块（320×320，圆角 48px），中间轮换服务商标志：Anthropic → OpenAI → DeepSeek → 火山方舟，每个 0.6s，最后停在中性的“模型”字样。
- 生成时：节点表面出现缓慢移动的细光纹（不是旋转 loading 圈），持续到输出结束。
- 发起工具调用：从节点边缘吐出紫色调用条，圆角 10px，文字 `openviking_read(release-plan.md)`。

### 4.5 OpenViking 记忆库

- 透视地面上整齐排列的文件卡，按目录分区，区名用小字标在地面上：`memories/events`、`memories/preferences`、`resources`、`sessions`。
- 地面中心有 OpenViking 标志的地面投影版（标志本体不变形，只是放在透视平面上，透明度 20%）。
- 检索光：从网关 `召回` 端口垂直落下的一道细光，落地后变成一圈向外扩散的扫描环，扫过的卡片轻微亮一下，命中的卡片保持亮起。

### 4.6 插件星座（01、05、09 镜）

- OpenViking 标志居中（Master 尺寸，≥64px），周围按两圈排布 10 个官方 Logo：内圈 Claude Code、Codex、Cursor、TRAE、opencode；外圈 Kimi Code、DeepSeek Harness、OpenClaw、Hermes、Pi。每个 Logo 放在白色圆形底座上（直径 120px），下方 22px 产品名。
- Logo 依次落位，错开 0.09s；每个落定后，从它到中心的细弧线用 DrawSVG 画出（0.5s，1.5px，青色 40%）。
- 只有 Claude Code 节点在 01 镜被推近展示“自动召回 / 已捕获”两行，其余节点不播放各自的自动化动画（各宿主能力有差异，见 Logo 来源清单）。
- 05、09 镜里星座退到远景（far 层），每个 Logo 右下角带一个 12px 的 OpenViking 小标记，表示插件“装在 Agent 里”。

### 4.7 集成工作卡与 MCP 插槽（只在 02 镜）

- 小号代码卡（白底，JetBrains Mono），每张一个函数名。堆叠时每张偏移 (6px, 8px)，旋转 ±2° 随机，错开 0.12s 入场。
- 两个应用同时堆；第三、四个应用轮廓淡入后加快到 0.08s 间隔，制造“越来越多”的压迫感。
- MCP 插槽：工作流流程图上方三个插槽 `工具`、`自动召回`、`自动保存`。挂上 MCP 后只有 `工具` 被填满（紫色），另两个保持虚线空框并轻闪一次。

## 5. 动作词典（统一参数）

| 动作 | 用在哪 | 参数 |
|---|---|---|
| 打字 | 02、03、04、07 | 40ms/字；标点后停 120ms；光标 530ms 闪烁 |
| 流式回复 | 02、04、06f、07 | 2–4 字一块，60–90ms 一块，句末停 200ms |
| Flip 变形 | 气泡 → 胶囊、面板 → 聊天窗 | 0.5–0.65s，`power2.inOut` |
| 弧线飞行 | 胶囊、记忆卡、调用条、星座连线 | MotionPath，弧高为距离的 18–25%，0.9–1.4s，`power2.inOut` |
| 扫描命中 | 记忆卡、控制台焦点行 | 描边扫过 0.5s，`none`；结束时 0.15s 亮度峰值 |
| 贴附 | 记忆段、工具结果段 | 0.3s，`back.out(1.4)`，只此处允许回弹 |
| 堆积 | 02 镜代码卡 | 错开 0.12s → 0.08s，每张 0.35s，`power3.out` |
| 失焦退后 | 03 转折、焦点切换 | blur 0→10px + scale 1→0.96 + 透明度 1→0.45，0.4–0.6s |
| 结晶 | 新记忆诞生 | 收拢 0.5s `power2.in` → 成卡 0.3s → 落地 0.6s `power3.out` |
| 大字入场 | 6 处大字 | 逐行，每行从 24px 下方、透明度 0 起，0.6s，`power3.out`；行间错开 0.25s；**落定后不再动** |

**统一禁令**：不让静止元素“呼吸”或漂浮；不对所有东西用同一个 slide-up；不让卡片无缘由地弹跳；不在镜头运动的同时让大字入场。

**镜头与连线的取舍**（全片 V3 复查后补充）：每次镜头移动都要对应旁白或画面里正在发生的动作；为了填补停留而加的慢速漂移、连续两次的小幅调整都去掉。连线只画有含义的连接（插件到 OpenViking、应用到网关再到模型、网关到 OpenViking 的通道），不画只为引导视线、两端不连任何东西的线。

### 6.2 企业应用界面：虚构但可信

## 8. 声音（无音乐）

没有音乐，旁白和音效要撑起整片节奏，所以样片阶段就要带声音。

- **旁白**：火山 TTS，“高冷沉稳 2.0”（`zh_male_gaolengchenwen_uranus_bigtts`），语速 +5（已确认）。每镜单独合成，用返回的字级时间戳对齐画面。理由和样本见 [音色样本](voice-samples/README.md)。
- **底噪**：全片铺一层极低的房间底噪（粉噪低通到 400Hz，-48 dBFS），避免数字静音的“断电感”。
- **音效清单**（全部短、干、轻，只在关键事件上用，不给每个 UI 动作配音效）：

  | 事件 | 声音 | 电平 |
  |---|---|---|
  | 打字 | 很轻的键盘声，每 2–3 字一个 | -34 dB |
  | 回车 / 发送 | 柔和的“嗒” | -28 dB |
  | 镜头长距离移动 | 低频气流 whoosh，0.8–1.2s | -30 dB |
  | 记忆命中 | 清脆单音 tick（约 2kHz，带短混响） | -26 dB |
  | 贴附 | 低沉的“咚”，像磁吸 | -27 dB |
  | 工具调用条吐出 | 比 tick 低一个八度的双音 | -28 dB |
  | 新记忆结晶 | 上行的三音琶音，0.4s | -26 dB |
  | 03 镜转折 | **全静音 0.5s**，然后第一下打字声 | — |
  | 落版 | 一个温暖的低频 swell | -24 dB |

- **混音**：旁白峰值 -3 dBFS，整体响度 -16 LUFS（适合会议室外放与线上平台）。音效全部压在旁白下方，与旁白同时出现时再降 4 dB。
- **音效来源**：用合成方式生成（正弦、噪声加包络），不依赖素材库，避免版权问题。

## 9. 制作流程与验收

**工程**：在本目录新建 `project/`，继续用 HyperFrames + GSAP（Flip、MotionPath 插件）。原因：环境已经跑通，ffmpeg 已就位；需要的是“世界 + 相机”的结构，不是换框架。和 codex 工程的区别：

- 一个 `world` 合成承载全部物件，不按镜头拆成独立页面；镜头只是相机时间线上的标签（`shot01`…`shot09`）。
- 物件写成可复用组件（胶囊、记忆卡、网关、模型节点、控制台），状态通过函数切换，如 `capsule.attach(memoryCard)`。
- 旁白音频按镜头接入，各镜开始时间由音频时间戳反推，画面跟声音走，而不是声音去凑画面。

**顺序**：

1. **样帧 K1–K9**（静态 PNG）→ 你确认视觉。
2. **06 镜样片**（约 25 秒，带旁白和音效）→ 你确认动效质感。这是最难的一镜，过了这一关，其余镜头只是工作量。
3. **全片粗剪**（全部镜头 + 旁白，音效简配）→ 确认节奏。
4. **精修**：音效精混、字幕、30 秒剪辑版。

**每轮验收**（审美问题优先于技术检查）：

- [ ] 随便暂停在任意一帧，画面都不像幻灯片
- [ ] 观众能不能一直跟住同一条消息、同一张记忆卡
- [ ] 每次镜头停稳时，画面里仍有事在发生
- [ ] 同一时刻只有一个焦点
- [ ] 屏幕上除了 6 处大字和角标，没有解说性句子
- [ ] 逐条对照脚本末尾的事实护栏
- [ ] 技术检查：无溢出、无字体回退、音画同步误差小于 2 帧、响度达标
