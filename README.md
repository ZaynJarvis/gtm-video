# gtm-video

用于集中存储和整理各个产品的公开视频物料，方便用户查找、观看和分享。

## 收录内容

- 产品介绍与功能演示视频
- 使用教程与上手指南
- 产品发布、更新和应用案例视频
- 配套封面、字幕及视频说明

## 组织方式

按产品建立目录，每个视频单独建一个子目录，例如：

```text
products/
  product-name/
    introduction/
      README.md
      video.mp4
      cover.png
      subtitles.zh-CN.srt
```

视频目录中的 README 建议写明标题、简介、语言、对应产品版本、发布日期、视频文件或观看链接，以及来源和使用授权。大体积视频可以使用公开托管链接，仓库保留说明与配套素材。对于代码生成的视频，也可只提交可重建工程：保留源码、配置、原始音频、时间戳和必要素材，忽略成片、逐帧截图、依赖目录及可重建中间产物。

## 添加物料

通过 Pull Request 添加或更新内容。请使用清晰的产品名和视频名称，只提交已获准公开的物料，并注明来源。具体转载、剪辑或其他使用方式以各物料标注的授权为准。
